# Even G2 — 用途地域による建物クリップ

## 挙動

中心タップで用途地域を ON にしたとき、**当該ポリゴンと交差する建物だけ**を 3D 描画する（紫の外環ラインは従来どおり）。

## 判定

`web/shared/geo/point-in-polygon.js` の `footprintIntersectsRingLonLat`:

- 建物外環の **いずれかの頂点**が用途地域内、または
- 外環頂点の **重心**が用途地域内

境界をまたぐ建物は、頂点が域外のみの場合は **全体が残る**（MVT 量子化・PoC 向けの近似）。厳密なポリゴンクリップは将来の CSG / ステンシル検討。

## フォールバック

クリップ結果が 0 件のときは **クリップ前の建物を表示**（メッシュ内に用途地域ポリゴンが無い／判定ミス時の真っ白回避）。
