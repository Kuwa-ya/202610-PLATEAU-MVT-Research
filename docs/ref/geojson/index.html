読込

`.zip` は解凍して一括読み込み、`.geojson/.json` はそのまま読み込みます。

API

GeoJSON取得にはJWT認証が必要です。

住所検索

住所APIはJWTではなく X-Address-Api-Key を使います。

地域メッシュから取得

地図上のメッシュをクリックして選択後、取得対象を選んで実行してください。黄色のメッシュが選択中です。
