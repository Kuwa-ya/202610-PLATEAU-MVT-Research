## 追加時のルール

- 継続更新する文書は、日付をファイル名に含めず Git 履歴で変更を追います。
- 特定時点のスナップショットであることが重要な場合だけ、本文とファイル名に日付を付けます。
- 外部 URL には、何を確認できるリンクなのかを併記します。
